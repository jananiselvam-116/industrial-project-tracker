# Industrial Project Tracker

A full-stack web application designed to manage and monitor industrial projects efficiently. The system provides role-based access for different users and helps manage project progress, tasks, documents, bills, tenders, and daily updates.

## 🚀 Features

- User authentication and authorization
- Role-based dashboards
- Project creation and management
- Project progress tracking
- Task management
- Daily project updates
- Document and bill uploads
- Tender management and applications
- Company and organisation management
- Employee and manager dashboards
- Government dashboard
- Secure API authentication
